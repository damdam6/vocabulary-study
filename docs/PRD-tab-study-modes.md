# 탭별 출제 유형 (#193)

## 사용자 설정

홈의 전체/탭 선택 아래 공통 도구 줄 왼쪽 **탭별 유형 설정**에서 모든 학습 탭(빈 탭 포함)을 조회한다. 탭마다 **뜻 보기(m1)** / **쓰기(m2)**를 체크하고 **설정 저장**을 누른다. 하나 이상 선택해야 저장할 수 있다. m1, m2, m1+m2 모두 지원하며 단어/문장 자동 분류는 하지 않는다. 저장 실패 시 선택값을 남겨 재시도할 수 있고 성공 안내를 표시하지 않는다.

명시적 탭 설정이 우선하며 미설정·신규 탭은 `profile.modes`를 사용한다. 설정 저장 후 홈으로 돌아오면 다시 조회하고 다음 학습에 반영한다. 프로필 기본값은 사용 가능한 기능의 제한이 아니라 미설정 탭의 기본 유형이다. 자동 발음 설정(#192)과 독립적이다.

## 저장과 탭 식별

- 스프레드시트는 인증된 프로필의 `sheetId`만 사용한다. 클라이언트가 스프레드시트나 프로필 ID를 지정할 수 없다.
- Google Sheets `properties.sheetId`를 탭 식별자로 사용하고 `title`은 화면 표시/기존 단어 API 호출에 사용한다.
- `_정보`의 A:B에 `[탭출제유형:<profile.id>, JSON]`을 저장한다. JSON은 `{ "탭 ID": ["m1", "m2"] }` 형태다. 같은 스프레드시트를 사용하는 프로필도 설정은 분리한다.
- 저장은 해당 프로필의 최신 전체 설정 스냅샷을 한 행으로 append한다. 같은 키의 **마지막 행**이 유효하다. 다른 설정 행을 덮어쓰지 않는다. 동시에 저장하면 Sheets에 마지막으로 반영된 스냅샷이 적용된다.
- 과거 설정 행은 이력으로 남는다. 학습 기록(D/E/F/G 이후)은 설정 저장에서 수정하지 않는다.
- 이름을 바꿔도 ID가 같으면 설정이 유지된다. 삭제한 탭 설정은 읽기에서 제외하고 다음 저장의 유효 스냅샷에서 제거한다. 같은 이름으로 재생성한 탭은 새 ID이므로 기본값을 사용한다. 삭제 후 Google Sheets에서 같은 ID를 수동으로 재사용하는 경우까지 구분하지는 않는다.
- `_`로 시작하는 탭은 설정 대상이 아니다. 조회 실패/손상된 모드 설정은 500으로 반환한다. 저장된 설정을 기본값으로 조용히 대체하지 않는다.

## API

`GET /api/tab-modes` → `{ tabs: [{ id: number, name: string, modes: ["m1"], explicit: boolean }] }`.

`POST /api/tab-modes` ← `{ tabs: [{ id: number, modes: ["m1"] }] }`. 지정한 탭을 수정하고 나머지 활성 탭 설정은 보존한다. 중복 ID, 잘못된 유형, 빈 유형 배열은 400, 존재하지 않거나 학습 제외된 탭은 409, 저장 실패는 500이다. 응답은 GET과 같다. 빈 탭 목록 요청은 기존 설정을 삭제하지 않는다.

`GET /api/words`는 각 단어에 `studyModes`를 포함한다. 홈 통계, 탭별 문제 수, 졸업 판정, 출제 큐는 이 값을 공통으로 사용한다. 구서버 응답처럼 값이 없으면 `profile.modes`를 사용한다. 빈 배열 등 잘못된 값은 클라이언트에서 오류로 표시한다.

`POST /api/answer`, `POST /api/review-fail`은 선택적 `studyModes`를 받는다. 신클라이언트는 홈 조회 결과의 유효 유형을 세션 큐에 고정하고, 모든 기록 및 localStorage 재시도 큐에 동일하게 보존한다. 서버는 인증된 프로필의 실제 학습 탭인지 확인하고 이 스냅샷으로 졸업/복습을 판정한다. answer.mode는 해당 스냅샷에 포함되어야 한다.

모드 스냅샷은 사용자 학습 선호이며 서명된 권한 토큰이 아니다. 인증된 사용자는 설정 API에서 m1/m2를 모두 선택할 수 있으며 기록 API에서도 유효한 유형 스냅샷을 지정할 수 있다. 다른 프로필이나 스프레드시트 접근 권한을 부여하지 않는다.

## 전환 및 진행 중 세션

| 상황 | 처리 |
|---|---|
| m1 전용 | m1 3회로 졸업 |
| m2 전용 | m2 3회로 졸업 |
| 두 유형 | 각 3회로 졸업 |
| 축소로 졸업, F열 없음 | 즉시 복습 대기로 표시. 첫 복습에서 일정 생성 |
| 축소로 졸업, 기존 F열 있음 | 기존 복습일/간격 유지 |
| 확대로 다시 학습 중 | 미달 유형 출제. 기존 카운트와 F열 유지 |
| 확대 후 재졸업 | 기존 F열이 있으면 보존. 없을 때만 내일/1일 생성 |
| 설정 변경 전 시작한 세션 및 미전송 기록 | 기존 `studyModes`로 처리. 새 설정은 홈 재조회 후 만든 새 세션에 적용 |
| 스냅샷 없는 구버전 기록 | 수신 시점의 탭 설정 사용. 현재 학습 중인 단어의 복습 오답은 일정 변경 없이 성공 응답. 복습 정답은 현재 졸업 상태일 때만 간격 증가 |

설정 변경은 카운트나 이력을 초기화하지 않는다. 쓰기를 껐다 켜면 보존된 m2 진행도를 다시 사용한다. 다른 브라우저에서 이미 열린 홈은 재조회 전까지 이전 스냅샷을 사용한다. 기존 재시도 큐의 4xx 폐기/5xx 보존 정책과 기록 중복 가능성은 변경하지 않는다.
