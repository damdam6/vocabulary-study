문서의 모드2 채점·입력·등록 규칙이 중국어 문장 구현과 어긋난다 (#178 리뷰 r1 미반영분)

1요약

#178(PR #184)이 독립 리뷰 r1의 changes_requested를 반영하지 않고 머지되어, 4개 문서가 #173~#177 구현 이전의 구규칙을 현재 계약처럼 적고 있다. 코드는 이미 맞다 — 모드2 채점은 contentType으로 분기하고(zh만 문장부호 제거), 긴 문장 글자 크기는 6단 스케일이며, 등록 병음 불일치는 차단이 아닌 경고다. 이번 작업은 문서만 5개 파일에서 정정한다 — 제품 코드는 건드리지 않는다.

2현황 분석

이슈가 지목한 6곳 모두 현재 main 문서에 그대로 남아 있음을 확인했다(라인 번호까지 일치):

  • 모드2 채점 분기 누락 — docs/PRD-general.md:104 "모드 2 채점은 콘텐츠 타입과 무관하게 공통 적용", :31 "학습 모델·시트 계약에는 영향이 없고", :68 "학습 모델에는 무관", :79 "zh에서는 v1과 동일하게 한자/병음/뜻". 실제로는 src/lib/studySession.ts:66-71의 gradeMode2가 contentType === "zh"일 때만 normalizeZhForGrading(문장 PRD §4 고정 문장부호 제거)을 적용하고 generic은 normalizeGenericForGrading(NFC·소문자화·공백 제거만)을 쓴다. docs/PRD.md:138(§5.2 3번)은 이미 이 분기를 정확히 서술하고 있어 참조처로 쓸 수 있다.
  • docs/design-prd.md:110 "콘텐츠 타입 무관 공통(PRD-general §4.2)", :131 "학습·채점 로직…엔 영향 없음 — 렌더링만 분기한다" — 같은 오류가 디자인 PRD에도 복제돼 있다.
  • placeholder 불일치 — docs/design-prd.md:139 표는 zh placeholder를 "汉字"로 적지만, 실제 구현 src/lib/contentLabels.ts:29-31(mode2Placeholder)은 zh에 "중국어"를 반환한다. 본문 :108도 이미 "placeholder '중국어'"로 맞게 적혀 있어, 표만 어긋난 상태다.
  • 글자 크기 표 불일치 — design-prd.md:43·:136은 "4자 이상 52px"로 3단만 적지만, src/lib/hanziSize.ts:8-18(hanziFontSize)는 6단이다: ≤2자 84 / 3자 64 / 4–8자 52 / 9–20자 40 / 21–50자 32 / 51자 이상 24. hanziSize.test.ts가 200자 24px을 고정해 이 스케일이 계약임을 뒷받침한다.
  • 등록 문서의 구규칙 — docs/plans/word-registration-system.md:70 "정상 / 오류(차단) / 중복"에 경고가 빠져 있다(:67-68과도 모순). :58은 schema_check.py를 "한자 유니코드 범위" 검증기로만 설명한다. 실제로는 src/lib/registerValidation.ts:17의 RowStatus가 "valid" | "warning" | "blocked" | "duplicate" 4종이고, :163-170이 병음 의미 불일치·자동 확인 불가를 "warning"으로 분류해 제출을 막지 않는다. 이 문서 자체에 이미 2026-09-24 개정 헤더(:8)가 붙어 "입력 문자·병음 경고 정책은 PRD-chinese-sentence-study.md §3이 대체한다"고 선언했는데, 본문(§5)은 아직 안 고쳐진 상태 — 개정 노트와 본문이 서로 불일치한다.
  • docs/plans/registration-generalization.md:52-53 §3.2 표가 zh A열을 "한자 기본 블록(U+4E00–9FFF)", B열을 "병음 필수 + 성조 부호 형식 + pinyin-pro 일치(클라만)"로 적어, 마치 pinyin-pro 불일치가 여전히 차단인 것처럼 읽힌다. 실측 결과 이 표는 이 플랜이 쓰인 2026-07-27 당시의 규칙이며, 이후 §3(등록과 데이터 계약)에서 문장·경고 정책이 개정됐다.
  • docs/PRD.md:139 — 모드2 결과 화면 문구가 "정답 한자·병음·뜻". 같은 절 위쪽(§4.2 A열)은 이미 "표제어(원문)" 같은 중립 용어를 쓰는데 이 줄만 zh 전용 "한자"가 남아 있다.

참조로 쓸 정정된 원본 두 곳도 확인했다: docs/PRD.md:138(§5.2 3번, contentType 분기가 이미 정확), docs/PRD-chinese-sentence-study.md §3(등록·병음 경고, :20-47)·§4(중국어 모드2 채점, :49-70).

3설계

모든 수정은 "코드가 이미 맞는 사실을 문서에 반영"하는 순수 정정이다 — 새 결정이나 트레이드오프가 없으므로 대안 비교는 없다. 원칙 두 가지만 지킨다:

  • 인용 최소화: 이슈가 요구한 문장·표 칸만 고치고, 각 문서의 다른 부분(예: registration-generalization.md 플랜 전체)은 재작성하지 않는다 — 완료 조건이 명시적으로 "플랜 전체 재작성 금지"를 못박았다.
  • 정정 출처 명시: 새로 적는 규칙은 현재 계약을 정의하는 문서(PRD.md §5.2, PRD-chinese-sentence-study.md §3·§4)를 참조하도록 적어, 다음에 또 규칙이 바뀌어도 문서 하나만 고치면 되게 한다.
