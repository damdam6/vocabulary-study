3설계

형식과 의미 검토를 분리한다. zh 분류는 공통 validateZhRegistrationWord를 호출하고 필드별 오류를 한국어로 표시한다. 원본 A/B는 파싱·편집 오버레이에서 보존하여 먼저 검사하고, 통과한 값만 공통 반환값으로 표시·전송한다. 뜻과 generic은 기존 trim 정책을 유지한다.

  • 행 모델: valid | warning | blocked | duplicate로 확장하고 차단/중복 사유와 검토 경고를 분리한다. 주 상태 우선순위는 blocked → duplicate → warning → valid. 중복 행에도 검토 경고가 있으면 보조 안내로 보존하되 주 상태 집계는 배타적으로 한다. 정상은 자동 검토 가능한 후보 일치를 뜻하며 발음 정확성을 보증하지 않는다.
  • 병음 검토: 일치 / 불일치 / 자동 확인 불가 결과를 명시한다. 형식을 통과한 값에서만 안전한 구분 부호·공백·아포스트로피를 비교용으로 처리하며 저장 원문에는 적용하지 않는다. 숫자·영문 혼합, 복수 후보가 있는 다음자, 一·不 및 연속 3성처럼 문맥·변조를 확정할 수 없는 경우는 보수적으로 자동 확인 불가를 반환한다. 후보에 없는 성조를 발견해도 오류가 아닌 경고다. 안내는 “병음을 자동 확인하지 못했어요. 원문과 함께 확인하세요.”를 사용한다. 단어/문장 길이 분류에 따라 정책을 바꾸지 않는다.
  • 연산 제한: 재귀 카티전 곱 대신 문자 위치·입력 병음 위치의 유한 상태 탐색을 사용하고 동일 상태를 재방문하지 않는다. 최대 20,000회 후보 전이 검사 예산을 두며 초과·후보 불명은 자동 확인 불가 경고다. 후보 중복 제거와 호출 내 문자 캐시를 사용한다. 테스트에서 예산 소진을 재현하고 미검증을 일치로 반환하지 않음을 확인한다.
  • 중복: 신규 zh 배치는 형식 검사를 통과한 행의 정규화된 원문만 중복 집계에 포함한다. 선택 탭은 NFC·trim 복사 키로 대조한다. 형식 오류 행이 정상 행을 중복으로 막지 않도록 격리한다. 문장부호·내부 공백은 보존하여 你好와 你好。를 구별한다. 기존 시트 행·기록 키는 변경하지 않는다. 중복 확인 서명은 선택 탭과 정렬한 중복 원문 목록을 구조적으로 JSON 직렬화하여 쉼표 충돌과 탭 변경 시 승인 재사용을 막는다.
  • 제출·수정: 정상+경고+중복을 전송하고 차단만 제외하는 기존 서버 최종 스킵 흐름을 유지한다. 네 상태 합계=전체, 전송 건수=정상+경고+중복이며 실제 추가 건수는 서버 응답으로 표시한다. 경고 전용 검토/수정 버튼으로 기존 모달을 재사용하고(중국어는 장문을 읽고 고치는 textarea, generic은 기존 input), 저장 후 배치 전체를 재분류한다. 표시값과 같은 무변경 저장은 기존 오버레이를 유지하고, 실제 변경을 원본의 유효한 정규화 표시값으로 되돌렸을 때만 직접수정 태그를 해제한다. 경고가 있다는 이유만으로 별도 확인을 강제하지 않는다. 오류/경고→정상/중복/차단 전환과 취소·직접수정 태그·탭 전환·재확인 무효화 계약을 유지한다.
  • 배치 크기: 공유 MAX_REGISTER_WORDS=100을 프런트·킷에 적용하고 101건 이상은 분할 입력 안내와 함께 차단한다. UI에서 일부 오류 행을 제외하는 정책은 유지하며 묵시적으로 100건을 잘라 보내지 않는다.
  • Python: 표준 라이브러리만 사용하는 단일 파일 배포를 유지한다. unicodedata NFC·코드 포인트 길이·고정 문자 목록·정규화 중복을 JS와 맞춘다. 원본 문자 검사 전 strip하지 않으며 Python strip의 공백 집합 차이가 zh 키를 바꾸지 않도록 허용 공백 및 JS trim 계약을 명시한다. generic 추출 필드 term/note/meaning과 선택적 note, 기존 추가 필드 검사·CLI 입출력/종료 코드를 유지한다.
  • 문서 범위: 중국어 킷에 단어·구·문장 추출, 내부 공백·문장부호·숫자·영문·원문 글자 보존, 병음·뜻 필수, 숫자 풀어쓰기와 약어 예제를 넣는다. 서버·킷 PASS는 형식 검사이고 발음 보증이 아님을 명시한다. 등록 화면의 안내·예제만 조정한다. 학습 채점(#175), 학습 레이아웃/모드 명칭(#176), TTS(#177), 전체 PRD 정합화(#178)는 후속 범위다.
