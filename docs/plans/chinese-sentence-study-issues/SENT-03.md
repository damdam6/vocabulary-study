# [SENT-03] 중국어 문장 채점에서 문장부호 차이를 허용하고 원문 키를 보존한다

## 현상 / 배경

중국어 단어뿐 아니라 문장도 같은 시트와 학습 진도로 공부하려는 요구다. gradeMode2는 공백만 제거하며 문장부호 차이를 오답 처리하고 contentType을 받지 않는다.

## 현재 동작

관련 위치: src/lib/studySession.ts, src/screens/Mode2Card.tsx, 채점·기록·재시도 관련 테스트.

## 기대 동작

문장 원문을 보존한 채 등록·학습하며 기존 단어와 generic 동작을 유지한다. 상세 계약은 상위 PRD 이슈의 본문 및 `docs/PRD-chinese-sentence-study.md`를 따른다. 새로운 문장 타입이나 시트 열은 추가하지 않는다.

## 완료 조건

- [ ] 채점 호출에 프로필 contentType을 전달하고 zh에만 PRD §4의 부호 제거 규칙을 적용한다.
- [ ] 숫자 사이 마침표/쉼표와 %, +, -, / 등 의미 기호를 보존한다. 전체 Unicode punctuation 제거는 사용하지 않는다.
- [ ] 문장부호 생략/전각·반각 문장부호/공백은 허용하고 한자·숫자·부정어·어순 차이는 오답 처리한다.
- [ ] 빈 정규화 결과와 부호만 입력은 오답 처리하고 generic은 기존 채점을 유지한다.
- [ ] 정답 API·재시도 큐·시트 갱신에 원문 tab+hanzi가 전달되고 결과 내 답은 사용자 원문임을 검증한다.
- [ ] PRD 채점 예시 표와 단어/generic/숫자 경계 회귀를 테스트한다.
