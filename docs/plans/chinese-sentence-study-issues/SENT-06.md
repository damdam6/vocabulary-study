# [SENT-06] 중국어 문장 등록부터 학습 기록까지 통합 검증하고 제품 문서를 정리한다

## 현상 / 배경

중국어 단어뿐 아니라 문장도 같은 시트와 학습 진도로 공부하려는 요구다. 등록·화면·채점·TTS 개별 변경만으로 원문 행에 진도가 기록되는 전체 흐름을 보장할 수 없다.

## 현재 동작

관련 위치: 등록·학습·Worker 통합 테스트, docs/PRD.md, docs/design-prd.md, docs/PRD-chinese-tts-audio.md, 등록 관련 계약 문서.

## 기대 동작

문장 원문을 보존한 채 등록·학습하며 기존 단어와 generic 동작을 유지한다. 상세 계약은 상위 PRD 이슈의 본문 및 `docs/PRD-chinese-sentence-study.md`를 따른다. 새로운 문장 타입이나 시트 열은 추가하지 않는다.

## 완료 조건

- [ ] 추출 킷 JSON→클라이언트 검증/경고→서버 등록→시트 조회→모드1/2→원문 행 기록 전체 경로를 검증한다.
- [ ] 문장부호 생략 정답이 올바른 원문 행에 1회 기록되고 한자 누락 오답·재시도·복습이 기존 정책을 따르는지 검증한다.
- [ ] 200/201자·병음 길이·불허 문자·중복·변조 경고·기존 장문·generic 회귀를 포함한다.
- [ ] npm test, npm run build, npm run lint 및 Python 킷 검사를 통과시키고 화면 320px/375px/데스크톱·IME 확인을 기록한다.
- [ ] 기존 PRD의 예문 비범위가 문장 자체를 학습 항목으로 삼는 이번 범위와 구별되도록 수정하고 등록/채점/디자인/TTS 문서의 구규칙을 정리한다.
- [ ] 실제 시트·유료 TTS·모바일 청취 미검증 항목을 명시하고 상위 추적 이슈에 완료 근거를 연결한다.
