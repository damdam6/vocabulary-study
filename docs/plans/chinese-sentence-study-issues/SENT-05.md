# [SENT-05] 문장 TTS의 원문 전달·길이 제한·문제 전환 동작을 검증한다

## 현상 / 배경

중국어 단어뿐 아니라 문장도 같은 시트와 학습 진도로 공부하려는 요구다. TTS API는 200자 문장을 수용하지만 등록·채점 변경 후 원문 유지와 기존 장문 UX를 함께 검증해야 한다.

## 현재 동작

관련 위치: src/hooks/usePronunciation.ts, src/lib/tts*, src/screens/*tts*test*, 필요시 worker TTS 통합 테스트.

## 기대 동작

문장 원문을 보존한 채 등록·학습하며 기존 단어와 generic 동작을 유지한다. 상세 계약은 상위 PRD 이슈의 본문 및 `docs/PRD-chinese-sentence-study.md`를 따른다. 새로운 문장 타입이나 시트 열은 추가하지 않는다.

## 완료 조건

- [ ] 문장부호·숫자를 보존한 A열 원문을 기존 TTS 경로에 전달하고 채점용 정규화 텍스트가 전달되지 않음을 검증한다.
- [ ] 기존 시트 200자 초과 항목은 표시/학습을 유지하고 음성 요청을 보내지 않으며 길이 안내를 제공한다.
- [ ] 모드1 공개 후/모드2 오답 후 자동 1회와 수동 반복, 캐시 재사용을 검증한다.
- [ ] 다음 문제/종료 시 취소와 지연 응답 차단을 검증하고 TTS 실패·비활성·자동재생 차단이 채점/기록을 막지 않게 한다.
- [ ] 제공자·R2 키 계약을 임의 변경하지 않고 B열이 발음 힌트로 사용되지 않는 현행 계약을 유지한다.
- [ ] mock 통합 검사와 실제 유료 합성/모바일 청취 여부를 구분해 기록한다.
