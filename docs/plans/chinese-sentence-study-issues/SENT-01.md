# [SENT-01] 중국어 문장 등록의 공통 입력 계약과 서버 검증을 확장한다

## 현상 / 배경

중국어 단어뿐 아니라 문장도 같은 시트와 학습 진도로 공부하려는 요구다. 서버는 A열에 한자만 허용하고 B열에도 문장부호를 허용하지 않는다.

## 현재 동작

관련 위치: worker/lib/register.ts, worker/routes/register.ts, 등록 관련 테스트 및 공통 fixture.

## 기대 동작

문장 원문을 보존한 채 등록·학습하며 기존 단어와 generic 동작을 유지한다. 상세 계약은 상위 PRD 이슈의 본문 및 `docs/PRD-chinese-sentence-study.md`를 따른다. 새로운 문장 타입이나 시트 열은 추가하지 않는다.

## 완료 조건

- [ ] PRD §3의 허용 문자·NFC·trim·200 코드 포인트·병음 1,000 코드 포인트·필수 필드 규칙을 공통 계약으로 구현한다.
- [ ] 한자 포함 숫자/영문 혼합과 문장부호를 허용하고 제어문자·숫자 성조·빈 값·초과 길이를 차단한다.
- [ ] 선택 탭/배치 중복 비교는 NFC·trim을 적용하되 기존 원문 행과 학습 기록 키를 수정하지 않는다.
- [ ] 100건 배치 제한, version 1, 기존 generic 검증 및 append-only 저장을 유지한다.
- [ ] 다음 이슈가 사용할 경계·혼합·단어·문장·generic 공통 fixture와 서버 테스트를 추가한다.
