# [SENT-04] 긴 중국어 문장을 읽고 입력할 수 있도록 학습 화면을 개선한다

## 현상 / 배경

중국어 단어뿐 아니라 문장도 같은 시트와 학습 진도로 공부하려는 요구다. 모드1은 4자 이상 52px이며 모드2가 한 줄 input을 사용해 긴 문장의 읽기·수정이 어렵다.

## 현재 동작

관련 위치: src/lib/hanziSize.ts, src/screens/Mode1Card.tsx, src/screens/Mode2Card.tsx, 관련 CSS와 contentLabels.

## 기대 동작

문장 원문을 보존한 채 등록·학습하며 기존 단어와 generic 동작을 유지한다. 상세 계약은 상위 PRD 이슈의 본문 및 `docs/PRD-chinese-sentence-study.md`를 따른다. 새로운 문장 타입이나 시트 열은 추가하지 않는다.

## 완료 조건

- [ ] 짧은 단어의 강조를 유지하면서 200자 문장과 1,000자 병음·긴 뜻·오답을 줄바꿈/크기 조정/스크롤로 표시한다.
- [ ] 중국어 모드2는 textarea를 제공하고 Enter 제출, Shift+Enter 개행, IME 조합 Enter 제출 방지를 테스트한다.
- [ ] 문제 전환의 입력·포커스·높이·스크롤 초기화를 검증한다.
- [ ] 320px·375px 모바일 및 데스크톱의 앞/뒷면·입력/오답 화면에서 텍스트와 판정/제출/다음/발음 버튼이 가려지지 않는다.
- [ ] 단어·문장을 포괄하는 중국어 라벨/힌트를 적용하되 기존 시트 헤더와 generic 계약은 유지한다.
- [ ] #169의 최신 Speaker Position 디자인을 확인해 병합 충돌과 접근성 회귀를 방지하고 화면 검증 증거를 남긴다.
